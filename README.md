# Edge-disjoint clique packings

By Jialin He.

This repository contains three related, independent research manuscripts on edge-disjoint clique packings, covering graphs near the Turán threshold, graphs with forbidden subgraphs, and almost complete graphs.

1. [Second-order asymptotics for edge-disjoint clique packings](Second-order%20asymptotics%20for%20edge-disjoint%20clique%20packings.pdf) — 16 pages.

   For each fixed clique order, the paper determines the optimal second-order term for integer and fractional clique packings above the Turán threshold when the edge excess is superlinear and subquadratic in the number of vertices. It also characterizes the full range in which the minimum possible packing number is asymptotic to the edge excess.

2. [Clique packings in graphs with forbidden subgraphs](Clique%20packings%20in%20graphs%20with%20forbidden%20subgraphs.pdf) — 14 pages.

   The paper studies how forbidden subgraphs affect clique packing bounds, including a classification by the chromatic number of the forbidden graph. Further results give sharp density bounds under forbidden-clique assumptions.

3. [Sharp clique packings in almost complete graphs](Sharp%20clique%20packings%20in%20almost%20complete%20graphs.pdf) — 19 pages.

   The paper determines sharp asymptotics for the edges left uncovered by optimal integer and fractional clique packings in almost complete graphs. The results include the contribution of degree divisibility, profiles for a linear number of missing edges, and stability when the number of missing edges is superlinear.
